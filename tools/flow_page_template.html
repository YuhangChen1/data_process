72 个评测算子

统一接口 fn(ctx: EvalContext) → Result，由 eval.score 全部执行，不做筛选

每个算子只读取它声明的 ctx 字段。case 提供不了所需输入时（例如静态场景没有主体）返回 n/a 并写明原因；运行出错时返回 error 并附 traceback，不会中断整次评测。WBench 的 MegaSaM 位姿会作为 c2w_est 交给重访漂移算子。右列是试点 oracle（扫描原始 3DGS，作为上界）的结果。

输入：EvalContext

字段来源
frames [T,H,W,3]被测模型按每一步渲染的画面
c2w_cmd, K, fpscase 的 cameras.npz（指令轨迹）
input_index, input_gt10 个输入步及其真值帧
keypoints, turns, actions6 个关键点的出发/返回步与 3+3 动作
pairs关键点重访对 + R2M revisit / baseline / short 配对
objects关键点处的标注物体 mask（来自 3D 标注）
depth, c2w_est可选：模型深度；MegaSaM 估计轨迹
scene_text, settingGPT 写的场景描述（设定遵循类用）

输出：Result（写入 scores.json）

字段含义
value标量分数（WBench 类为 0–100，R2M 类为 NMR）
statusok / n/a / error
unit, higher_is_better单位与方向
raw中间量：MG、各配对组均值、对齐尺度等
per_item逐帧 / 逐关键点 / 逐配对的值
note, secondsn/a 或代用说明；耗时

约定

坐标：扫描原始坐标 −Y 朝上（gaussian.ply、mesh、董婷的 poses.json）；管线内部统一到调平后的 canonical Z 朝上坐标系，变换矩阵在 analysis.json:world_to_canonical。cameras.npz 同时给出 c2w_source 和 c2w_canonical。

相机：OpenCV 约定（+X 右、+Y 下、+Z 前），矩阵是相机到世界；像素中心在 (u+.5, v+.5)。

单位：推断米制（按层高推断，没有独立标定）。深度 PNG 是 uint16 毫米，0 表示无效。

ID：global ID 唯一来源是 fine_instances.npz:point_fine_ids，0 表示未知；剔除的碎片记录在 global_instances.json:dropped_instances。

模型：GPT 调用统一使用 gpt-6.1-sol；分割使用 SAM3；评测用到 MegaSaM、DA3、DINOv2、CLIP、LPIPS、DreamSim、GroundingDINO、SAM2、LightGlue 等，权重全部离线读取。
